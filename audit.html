Synthetic incidents deliberately reuse a small vocabulary and grammar across splits. Shared templates here are a generator-design feature: high scores on this task cannot be interpreted as generalization to new incident narratives. Random host IDs/usernames do not create independent semantic templates. Mixed-label components warn that lexical similarity is not equivalent to shared ground truth, especially for negation.

Cross-dataset contamination

36 candidate public-source pairs meet ≥.90 similarity in a separately fitted shared representation with the same length constraints. Labels mean phishing in one corpus and spam in the SMS proxy, so even equal numeric labels are not equivalent tasks. These pairs do not leak between models trained separately, but they weaken any claim that the public datasets are wholly independent evidence.

The exported split manifest includes both the exact original seed-17 splits and candidate whole-component splits at .90. Four shuffled StratifiedGroupKFold folds are constructed; the fold closest to a 25% test fraction and balanced test labels is chosen without consulting model scores. Every row is assigned exactly once and no qualifying ≥.90 edge crosses the candidate split. Counts and class balance differ from the original 600/200 design; some giant components may make a balanced split impossible. Component disjointness is necessary for this proxy, not proof of campaign separation.

Recommended interpretation and next experiment

  • Keep the original leaderboard as within-source random-split performance, not new-campaign performance. Preserve it rather than silently replacing its meaning. Original row-level bootstrap intervals and McNemar tests do not account for template clustering and are exploratory, not campaign-level inference.
  • Rerun baselines and DistilBERT on the same grouped split manifest, with a separately grouped validation set if tuning. Report class counts and group counts; use group-aware uncertainty, not row-independent bootstrap alone.
  • Obtain genuine campaign/thread/source/date metadata for a campaign or temporal holdout. Known shared parent-source datasets must be treated as overlapping evidence.
  • Review positive-label semantics before a phishing-only claim. Template grouping does not transform generic spam into phishing ground truth.
  • Do not use synthetic template success as deployment evidence. Add genuinely held-out generator grammars and events before claiming out-of-template transfer.

Method and reproducibility

All 2,400 frozen records were audited; no new data were downloaded. Case, URLs, emails, long hashes and numbers are normalized as explicit slots; non-letter punctuation is removed. L2-normalized character 4–5-gram TF-IDF uses sublinear TF and at most 30,000 features per dataset. Cosine edges are accepted only when both normalized texts have ≥40 characters and the shorter/longer normalized-length ratio is ≥.5. This detector can miss paraphrased campaigns, multilingual variants and shared quoted fragments below threshold; it can overmerge common boilerplate. Audit features intentionally see all texts, which is acceptable for detecting overlap but must not be reused as trained classifier features.
