Statistical inference: no independent-seed shortcut

For each dataset/seed/condition, 2,000 bootstrap draws resample whole test components, stratified by their observed class. All frozen components are label-pure. The resulting pointwise macro-F1 intervals are conditional on that fitted model and observed groups; they exclude training-sample uncertainty and are not multiplicity-adjusted. Very small synthetic group counts limit their reliability.

Paired accuracy tests swap classifier correctness totals within whole components, using exact enumeration for ≤16 nonzero-difference groups and 10,000 swaps otherwise (plus-one Monte Carlo correction). All 300 new per-split comparisons versus word SVM share a global Holm correction, valid under arbitrary p-value dependence if the individual swap assumptions hold. These are accuracy tests, not macro-F1 tests. Historical test families remain separate. We do not run a t-test on five overlapping split scores or pool 1,000 test appearances as independent observations.

Execution and reproducibility

Baseline estimators, hyperparameters, training-only TF-IDF features and corruption functions are unchanged. New jobs share identical label-independent word matrices across NB/LR/word SVM and across clean/noisy-label fits; character features have their own matrix. Majority predictions use the mathematically equivalent most-frequent training label directly (smallest label breaks a tie). All six clean predictions on the phishing seed-17 split were recomputed by this fast path and matched the original pipeline exactly. Clean fits are reused for test-only corruptions; 15% label flips apply to that split's training order using its seed.

For speed, new timing rows decompose a cached batch transform plus warmed classifier prediction; old seed-17 rows retain prior full-pipeline timing. An unrelated transformer job remained active. Therefore the aggregate leaderboard deliberately omits pooled runtime statistics; raw timings are not controlled speed comparisons.

Completed job directories are reused. Delete only the jobs directory to refit all newly evaluated splits; seed-17 reference cells are always reused after verification.
