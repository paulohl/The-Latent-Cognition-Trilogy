# Latent Cognition — Research Canon

The **research canon** separates the architectural foundation, the three-volume theoretical sequence, companion hypothesis papers, and parallel experimental or applied investigations. This distinction is scientific, not merely organizational: related work is not automatically evidence for every proposition in the Trilogy.

## Canonical relationships

```text
                   ARCHITECTURAL FOUNDATION
                  DLI-LLM (separate manuscript)
                             │
                       informs
                             │
          MAIN THEORETICAL SEQUENCE (THE TRILOGY)
         ┌───────────────────┼───────────────────┐
   Volume I / M        Volume II / S        Volume III / R
   Memory Fields       Symbol Fields       Routing Fields
         └────────────── reciprocal ──────────────┘
                    operator coupling

     COMPANION HYPOTHESES       PARALLEL INVESTIGATIONS
     Supporting claims         Benchmarking and applied domains
     (separate works)          (separate evidentiary status)
```

This is a **canonical map, not a dependency or execution graph**. The analytical order M → S → R should not be read as a mandatory sequential process. The conjectured coupling conditions must be tested.
